# Mito

Landing page design study for a quest app, in English (`/`) and Spanish (`/es`).

- `npm run dev`: local server
- `npm test`: tests
- `npm run typecheck` and `npm run lint`: checks
- `npm run build`: production build

All copy is in `src/content.ts`. Photos are in `public/photos`, with sources in `CREDITS.md`. Placeholder Totems come from `buildTotem` in `src/three/totemModels.ts`.
